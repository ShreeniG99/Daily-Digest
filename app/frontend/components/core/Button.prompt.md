Primary text button for key actions ("Read all", "Apply", "Load new items").

```jsx
<Button variant="primary" icon="volume-2">Read all unread</Button>
<Button variant="secondary" size="sm">Filters</Button>
<Button variant="ghost" iconRight="chevron-right">See all</Button>
```

Variants: `primary` (sienna), `secondary` (cream + border), `ghost`, `danger`. Sizes `sm | md | lg`; `block` for full width; `icon` / `iconRight` take any Icon name.
